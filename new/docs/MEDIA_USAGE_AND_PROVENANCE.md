Projects (9): `unipirate`, `moneo`, `nox`, `worldsim`, `dreamtransport`, `voice_oasis`, `klebl`, `mhack`, `swissinsight`.

Hackathon award reels (5): `mittelstand`, `techeurope`, `starthack`, `swisshacks`, `servusai`.

All files are in `public/portfolio-media/`, with `projects/`, `hackathons/`, and `posters/` directories. See `src/data/project-media.ts` for exact paths and descriptions.

## IMPORTANT: What these animations are (and aren't)

These are original, **procedurally illustrated storyboards** for the products and events. They are **not screen recordings of working applications** and should not be described as such. They use demo content and general flows justified by project documentation; they do not prove a capability works in production. Moneo's chart/data are entirely fictional examples. The WorldSim and DreamTransport visualizations are abstract and not predictions or mapped real-world results.

The five hackathon loops currently contain designed graphical award cards **without photographs**, because the original image files weren't accessible to the animation-generation environment. Your old `Portfolio/public` directory *does* hold the images. Codex can either place real photo galleries beside each loop (preferred for authentic personal presentation) or rerun the generator after checking image rights and placements to create photo-integrated reels.

## To rerender hackathons with original photos

From the extracted handoff directory, with Python 3.11+, Pillow, NumPy and ffmpeg installed:

```bash
python -m pip install -r scripts/requirements-media.txt
python scripts/generate_portfolio_media.py --output public/portfolio-media --existing-assets /absolute/path/to/old/Portfolio/public
```

The generator reads these existing filenames from the original repo: `mittelstadt.png`, `mittelstand2.jpeg`, `mittelstand3.jpeg`, `munichhack.jpeg`, `starthack.jpg`, `start_hack2.jpeg`, `swisshacks1.jpeg`, `swisshacks2.jpeg`, and `dream_transport.gif`. It does not copy source photographs into the handoff.

Photos should be actual event photos and used in the appropriate event; do not substitute fabricated people or event shots.

## Playback

- Use `<video muted loop playsInline poster="..." preload="none">`, with `IntersectionObserver` to play only when visible; pause when out of view.
- For `prefers-reduced-motion: reduce`, show poster only. The optional React `PortfolioMotion.tsx` provides a starting implementation.
- Provide accessible project titles, text descriptions and keyboard-friendly action links outside the video.
- Avoid audio, giant GIF files, autoplaying every clip at page load, or embedding base64 media in JS bundles.
- These are intentionally short 5–7 sec loops sized for card previews, **not full-length demos**. Use real sanitized app recordings for the detailed case studies if available.
