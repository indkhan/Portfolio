# Media export

- `projects/*.mp4`: 9 animated project concepts.
- `hackathons/*.mp4`: 5 animated award highlight concepts.
- `posters/*.webp`: matching thumbnails/fallbacks.
- Silent 16:9 H.264 960×540 at 15 frames per second; duration 5–7 seconds per video.

Animations are **illustrations**, not screen recordings of the products. Hackathon originals are preserved in your original Portfolio `public/` repository rather than packaged as copies here. For details and optional photo-integrated rebuild, see `docs/MEDIA_USAGE_AND_PROVENANCE.md` in the complete handoff ZIP.
